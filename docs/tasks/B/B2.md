- Must parse every source type present in data/synthetic/ into correctly-typed RawRecord objects.

## 12. Acceptance Criteria

- Running fetch_batch() twice in a row yields identical record_id sets.
- Every bundled source type in data/synthetic/ is represented in the output.

## 13. Tests Required

- Unit tests reading fixture files and asserting correct RawRecord shape and field population.
- An idempotency test (two consecutive calls, compare record_id sets).
