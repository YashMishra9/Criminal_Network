## 10. Exact Interfaces/Contracts to Follow

- Rule 1: read-only (no CREATE/MERGE/SET/DELETE/REMOVE). Rule 2: CALL/any procedure forbidden outright, no whitelist. Rule 3: only MATCH/OPTIONAL MATCH/WHERE/RETURN/WITH/ORDER BY/LIMIT/SKIP/path functions permitted. Rule 4: schema-only labels/types. Rule 5: dataset filter enforced/injected. Rule 6: bounded timeout.

## 11. Implementation Requirements

- Reject ANY query containing a CALL clause unconditionally — no exceptions, no convenience whitelisting in this version.
- Reject queries referencing labels/relationship-types outside DOC3 §6.
- Reject queries lacking or mismatching the requested dataset filter.

## 12. Acceptance Criteria

- Adversarial test queries (a mutating clause, a CALL apoc.* clause, an out-of-schema label, a cross-dataset query, and a timeout-inducing query) are ALL rejected — this is an explicit, required test per DOC4's Track F Definition of Done.

## 13. Tests Required

## 14. Definition of Done
