## 2. Track

## 3. Objective

Implement all five EvidenceResolver methods per DOC3 §9.1: for_entity, for_relationship, for_finding, for_resolution_decision, for_case_item.

## 10. Exact Interfaces/Contracts to Follow

- for_entity(entity_id) -> Evidence[]  — via ResolutionDecision.source_record_ids (§2.5)
- for_relationship(relationship_id) -> Evidence[]  — via the relationship's single EdgeRef (§6.5)
- for_finding(finding_id) -> Evidence[]  — via direct Evidence-[:SUPPORTS]->Finding (§1.8)
- for_resolution_decision(decision_id) -> Evidence[]  — via decision.source_record_ids directly
- for_case_item(case_id, item_type, item_id) -> Evidence[]

- This must be the ONLY place Evidence nodes are queried from — no other component may query Evidence directly (DOC3 §9.1 rule).
