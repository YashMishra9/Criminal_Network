## 1. Task ID and Title

**A4 — Neo4j Connection Layer**

## 2. Track

Track A (see DOC4 §3 for the full track description and DOC4 §1 for where this track fits in the overall dependency structure).

## 3. Objective

Implement Neo4j driver/session management, connection pooling, and a health-check function.

## 4. Why This Task Exists

Every track that touches the graph (C, D, F, G) depends on this single connection layer.

## 5. Dependencies

A2

## 6. Relevant DOC1/DOC2/DOC3 Sections

- DOC2 §15 (Neo4j Aura / self-hosted deployment)
- DOC2 §5.2 (single Neo4j instance decision)

## 7. Inputs

- Config (Neo4j URI/credentials) from A2

## 8. Expected Outputs

- A get_session()-style accessor and a health_check() function

## 9. Files/Modules to Create or Modify

- backend/app/graph/connection.py

## 10. Exact Interfaces/Contracts to Follow

- None new — wraps the official Neo4j Python driver.

## 11. Implementation Requirements

- Use the official neo4j Python driver with connection pooling.
- Provide a health_check() function returning False (not raising) when the database is unreachable, so callers can map this to the graph_unavailable error type (A6) without a crash.
- This must remain the ONLY Neo4j connection in the system — do not introduce a second database connection anywhere (DOC2 §5.2).

## 12. Acceptance Criteria

- Connects successfully to a configured Neo4j instance.
- health_check() returns False (never raises) when the database is down.

## 13. Tests Required

- Integration test against a real or containerized test Neo4j instance.
- A test simulating an unreachable database and confirming health_check() degrades gracefully.

## 14. Definition of Done

Connection layer is stable and usable by C1 onward.

## 15. Parallelization Information

Parallel with A1, A3, A5, A6. Depends only on A2.

## 16. Integration / Sync Point

Contributes to Sync 1.

## 17. Explicit Constraints — Things This Task Must NOT Do

- Single Neo4j instance only — do not add a second database or connection pool for any other store.
